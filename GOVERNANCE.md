# Governance

`carry-trade-model` is currently maintained by Aidan Marshall. The project uses
a lightweight maintainer model appropriate for an alpha research project.

The maintainer decides what merges and releases. Changes to public commands,
data provenance, model methodology, API contracts, security posture, or trading
safety boundaries require tests and documentation. The repository will remain
research- and paper-oriented unless a separately reviewed release explicitly
changes that scope.

Releases are cut from `main` after Python tests, model validation, system
evaluation, package checks, frontend build/audit, and security workflows pass.
Release notes must identify material methodology, dependency, compatibility,
and data-source changes.
