# Carry Trade Dashboard

A local research dashboard for carry trade modeling and analysis, showing API-backed FX rates, optional sentiment logs, model outputs, and performance logs when those inputs are available.

## Architecture Overview

### Frontend (React TypeScript)
- **Dashboard**: API-backed data visualization
- **Components**: Modular cards for different data types
- **Styling**: Tailwind CSS for responsive design
- **API Integration**: Axios for backend communication

### Backend (Python Flask)
- **API Server**: RESTful endpoints serving JSON data
- **Data Integration**: Reads logs and model outputs generated by the Python tools
- **Real Data Posture**: Provider data and local logs where available
- **CORS Configuration**: Local dashboard origins by default

## Features

### 📊 FX Rates Card
- USD/UAH and EUR/UAH exchange rates from the backend API
- Change indicators with color-coded trends
- API data status indicator

### 📈 Sentiment Analysis Card
- Regional sentiment scores (USD, EUR, UAH)
- Confidence levels and sentiment labels
- News sentiment from local logs or configured providers

### 🎯 Performance Metrics Card
- Total return and Sharpe ratio
- Maximum drawdown and win rate
- Volatility measurements
- Benchmark comparisons

### 🤖 Model Predictions Card
- Research return forecasts from backend output
- Confidence levels with visual indicators
- Multi-horizon predictions (7, 30, 60, 90 days)

### 🚀 Trading Signals Card
- Research BUY/SELL/HOLD signal labels
- Signal strength indicators
- Expected returns and risk assessments

### 📰 Market News Card
- Financial headlines when news logs or providers are configured
- Sentiment-analyzed news stories
- Regional news categorization

### 📊 Macro Data Card
- Economic indicators (Fed Funds, CPI, etc.)
- Change tracking from previous values
- Visual trend indicators

## Installation & Setup

### Prerequisites
- Python 3.9+
- Node.js 20.19+ for the Vite dashboard
- Virtual environment (recommended)

### Backend Setup

1. **Activate virtual environment**:
   ```bash
   # Windows
   venv\Scripts\activate
   
   # macOS/Linux
   source venv/bin/activate
   ```

2. **Install Python dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Start the backend server**:
   ```bash
   python api_server_real_data.py
   ```

### Frontend Setup

1. **Navigate to frontend directory**:
   ```bash
   cd frontend
   ```

2. **Install Node.js dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm start
   # Or use the batch file:
   run_frontend.bat
   ```

## API Endpoints

### Core Data Endpoints
- `GET /api/dashboard` - Complete dashboard data
- `GET /api/fx-rates` - FX rates from Yahoo Finance/logs where available
- `GET /api/sentiment` - Market sentiment analysis
- `GET /api/macro` - Macroeconomic indicators
- `GET /api/predictions` - Research model outputs or heuristic forecasts
- `GET /api/signals` - Trading signals
- `GET /api/performance` - Performance metrics
- `GET /api/news` - Market news headlines

### Utility Endpoints
- `GET /health` - API health check
- `POST /api/update-model` - Disabled by default; set `ENABLE_MODEL_UPDATE_ENDPOINT=true` only for local research use

## Data Sources

### API-Backed Data
- **FX Rates**: `logs/fx/fx_log.csv`
- **News Sentiment**: `logs/news_log.csv`
- **Performance**: `logs/performance_log.csv`

### Historical Data
- **Macro Data**: `logs/macro/*.csv`
- **Headlines**: `*_headlines.csv` files
- **FX History**: `logs/fx/*_Historical_Data.csv`

## Configuration

### Environment Variables
Create `.env` file in frontend directory:
```
VITE_API_URL=http://127.0.0.1:8000
```

### Backend Configuration
- Default port: 8000
- Default host: `127.0.0.1`
- CORS defaults to local dashboard origins. Use `CORS_ORIGINS` for intentional changes.
- Debug mode is opt-in with `FLASK_DEBUG=true`.

## Development

### Adding New Components
1. Create component in `frontend/src/components/`
2. Add TypeScript interface in `types/index.ts`
3. Import and use in `Dashboard.tsx`

### Adding New API Endpoints
1. Add route in `api_server_real_data.py`
2. Update API service in `frontend/src/services/api.ts`
3. Add data loading function if needed

### Styling Guidelines
- Use Tailwind utility classes
- Follow component-based structure
- Maintain responsive design patterns
