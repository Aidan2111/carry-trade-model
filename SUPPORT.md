# Support

Use GitHub Issues for reproducible bugs and focused feature requests. Include
your operating system, Python and Node versions, the command run, sanitized
output, and whether optional API keys or local data were configured.

Use GitHub Discussions, when enabled, for setup questions and research ideas.
Security reports belong in the private channel described in `SECURITY.md`.

This is a maintainer-supported research project without an uptime or response
SLA. Questions asking for personalized investment recommendations or live
trading instructions are out of scope.
